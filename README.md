# zunyan9.github.io

홍준우 UX/UI 디자이너 포트폴리오 → https://zunyan9.github.io

## 고치는 법

- **스크린샷 넣기**: `images` 폴더에 이미지를 올리고, 프로젝트의 `<div class="thumb">스크린샷 추가 예정</div>`를 `<div class="thumb"><img src="images/파일이름.png" alt="설명"></div>`로 바꿔요.
- **프로젝트 추가**: `<article class="project">` 블록 하나를 복사해서 내용을 바꾸면 돼요.

GitHub 웹에서 파일을 열고 연필 아이콘으로 바로 수정해도 되고, 저장하면 1~2분 뒤 사이트에 반영돼요.
